ZKTeco Biometric Attendance Integration

Integrate ZKTeco biometric devices with Odoo using a reliable queue-based attendance processing system.

Overview​

This solution enables seamless synchronization of attendance data from ZKTeco biometric devices into Odoo. Attendance punches are collected from devices, validated, queued, and processed into Odoo attendance records while maintaining data integrity and preventing duplicates.

Key Features​

  • Multiple device support
  • TCP and UDP connectivity
  • Attendance synchronization
  • Employee-device mapping
  • Queue-based processing
  • Duplicate prevention
  • Attendance conflict handling
  • Automatic scheduled processing
  • Detailed processing logs
