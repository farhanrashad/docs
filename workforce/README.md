# Workforce Operations Suite

The Workforce Operations suite provides the core app shell, shift planning, and shift attendance documentation for Odoo 18 Community.

## Modules

| Module | Description |
|--------|-------------|
| Workforce Operations | Core framework, root menus, and shared configuration |
| Shift Planning | Shift templates, team allocation, and rotation planning |
| Shift Attendance Link | Attendance-to-shift matching and shift context on attendance screens |
