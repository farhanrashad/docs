# Workforce Operations

## Overview

Workforce Operations is the core framework for the suite. It provides the shared application shell, root menus, and configuration hub used by dependent workforce modules.

## What It Covers

- Shared Workforce app shell
- Configuration hub for workforce modules
- Base security groups and settings
- Home page for the suite documentation
